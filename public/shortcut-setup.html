spool
iPhone Share Sheet recipe · iOS 18

Make capture feel
invisible.

This is a one-time update. Afterward: Share a reel, choose what you want from it, and keep scrolling. You can select more than one.

01

Create it and enable sharing

Open Shortcuts, tap +, and name it “Save to Spool.” Tap Done. On the All Shortcuts screen, press and hold its tile, choose Details, and enable “Show in Share Sheet.” Reopen the shortcut, tap “Any” in the new Receive Input action, clear the types, and select URLs.

02

Add your four save choices

Before the web request, search Actions for List. Add four text items: Knowledge, Script, Creator, and Save only. Then add Choose from List. Tap its blue arrow and enable Select Multiple. Finally add Combine Text, choose the selected items as its input, and keep the separator set to commas.

List → Knowledge, Script, Creator, Save only
Choose from List → Select Multiple ON
Combine Text → separator: commas
03

Add the web request

Search Actions for “Get Contents of URL.” Add that exact action—not “Open URLs.” Remove the blue Shortcut Input bubble from its URL field, then paste the address below and expand the action using the blue circled arrow.

URL: https://YOUR-SPOOL-DOMAIN/api/capture
Method: POST
Request Body: JSON
04

Send the URL and choices

Under Request Body, add two Text fields. Set url to the blue Shortcut Input variable from the first action. Set intents to the blue Combined Text variable.

url → Shortcut Input
intents → Combined Text
05

Optional: ask for a tiny note

Add “Ask for Input” immediately before the web request, choose Text, and use the prompt “Why keep this? Optional.” Add one more Text field in the JSON body named sharedText, set to Provided Input. The note gives context only; your selected labels decide what Spool does.

sharedText → Provided Input

Knowledge: caption first; transcript only if the lesson is missing
Script: always transcribe
Creator: add to your Creator playbook
Save only: no Claude or Supadata cost
06

Save and test

Tap Done—do not use the blue Play button because it has no reel input. In Instagram, share a reel, choose Share to… or More, then tap Save to Spool. Pick one or more choices and allow access to Spool if iOS asks.

Credit smart:Knowledge first checks the public caption and page text with Claude. Supadata is used only if that material does not contain the real lesson. Spool never analyzes video visuals, your likes, or your saved collection.
